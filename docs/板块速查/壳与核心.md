## 二、核心概念与数据流

### 启动流程(`lib/main.dart`)
1. `WidgetsFlutterBinding.ensureInitialized()` → 锁竖屏 `SystemChrome.setPreferredOrientations([portraitUp])`。
2. `SettingsService.instance.loadVisualSettings()`:启动前载入主题模式/色板/背景图,避免首帧闪烁。
3. `AppLog.instance.init()` → `AiProviders.migrateLegacyIfNeeded()`(旧单中转站→提供商结构,幂等)。
4. 日志:主题模式 + 色板;`_configSummary()` 打印各联网服务**是否已配置的布尔摘要**(不含密钥,排障第一眼)。
5. `_maybeAutoBackup()`:开关开启且距上次备份 ≥7 天时,延迟 8 秒静默导出一次。
6. `runApp(StudentWorkbenchApp())`,`home: SplashPage()`。

### 导航结构
- **入口链**:`SplashPage`「开始今天」→ `AppRoutes.pushReplacement` → `MainShell`;启动页三个快捷入口(速记/闲话铺/记账)是 `push` 进入,返回后再 `pushReplacement` 到 `MainShell`(落到首页)。
- **MainShell 5 Tab**:`_index` 0 首页 / 1 计划 / 2 灵感速记 / 3 记账 / 4 闲话铺;0~3 直接 `setState` 切 body,4 是「启动器」Tab——`AppRoutes.push(ChatPage)` **全屏进入**(无底部导航),返回键回到本框架。
- **侧边栏 `AppDrawer`**:主框架 `drawerEdgeDragWidth: 160`(左缘 160px 热区);收纳二级模块(英文积累/健康管理/每日复盘/写日记/金币中心)与底部「系统设置」;点击模块先 `Navigator.pop()` 关抽屉再 `push`。
- **退出确认**:MainShell 包 `PopScope(canPop: false)`,返回键弹 `showConfirmDialog('退出应用?')`,确认后 `SystemNavigator.pop()`。
- **首次配置引导**:`initState` 延迟 600ms 后检查——未配置聊天服务且 prefs 键 `config_guide_done_v1` 未标记时弹引导(只弹一次),「去配置」直达 `ProviderListPage`。
- **跳转统一走 `AppRoutes`**(勿散落 `Navigator.push(MaterialPageRoute)`):
  - `push(context, page, {dialog})`:默认 `_FadeSlideRoute`(260ms 淡入 + 上滑 0.03,easeOutCubic/easeInCubic,下层背景图过渡期间可见);`dialog: true` 走 `MaterialPageRoute(fullscreenDialog: true)`(如灵感速记)。
  - `pushReplacement`:普通 MaterialPageRoute 替换,无过渡(启动页→主框架)。
  - `pushAndRemoveUntil`:清空导航栈(恢复备份后回启动页)。

### 背景图层级(`main.dart` builder 内 Stack,`StackFit.expand`)
1. **最底**:`ColoredBox(AppColors.background)` 兜底底色——任何情况窗口背景都是主题色,杜绝「透明脚手架+背景图未渲染→黑屏」。
2. **中层**:背景图开启且路径非空时,`Positioned.fill(RepaintBoundary(_buildBackground))`——`Opacity`(透明度 clamp 0.1~1)+ 模糊度 >0.5 才套 `ImageFiltered(ImageFilter.blur)`(省 GPU 开销);`Image.file` + `gaplessPlayback`,所有子页面共用、不随页面切换重新加载。
3. **顶层**:`child`(即 Navigator 内容)。

配套:背景图开启时 `AppTheme` 把 `scaffoldBackgroundColor` 设 `Colors.transparent`、AppBar 半透明(`surface` @0.62),让背景图透出;`main.dart` 与 `theme.dart` 两处用同一 `bgImageOn` 判定,改判定需同步。builder 每帧先 `syncAppBrightness(Theme.of(context).brightness)`,保证「跟随系统」下 `AppColors.*` 与实际显示一致。

### 主题 / 色板切换
- **数据源**:`SettingsService` 的 6 个 `ValueNotifier`(themeMode / palette / backgroundEnabled / backgroundOpacity 0.3~1.0 默认 0.85 / backgroundBlur 0~30 默认 0 / backgroundPath);`MaterialApp` 外包 `ListenableBuilder(Listenable.merge([...]))`,任一变化**重建整个 MaterialApp**(无需重启)。
- **色板**:`kAppPalettes` 共 6 套浅色板(blue 默认 / pink / green / yellow / black / white);**深色模式全局共用一套低亮度同色系 `_DarkColors`(不随色板切换)**。
- **语义色**:`AppColors.*` 全是 **getter**,按 `_isDark × 当前色板` 取值;特殊:`primarySoft`(浅色底,black/white 色板直接用 primary,其余 `lerp(primaryLight, white, 0.2)`,深色用 primary)与 `onPrimarySoft`(black/white 用 onPrimary 白字,其余用 primaryDark 深字,深色用深色 onPrimary)。
- **ThemeData 缓存**:`AppTheme._cache`,key = `亮度:色板:背景图开关`,同一组合复用同一实例;`_build` 里先 `syncAppBrightness` 再取值。
- **`themeAnimationDuration: Duration.zero`**:主题切换无渐变,与 `AppColors` 瞬时翻转保持一致。
- **focusedBorder 中性灰**:输入框聚焦边框用 `textSub` @0.55 中性灰蓝,不用主题色彩线框(视觉基调要求)。

### 全局字号阶梯缩放(`main.dart`)
- `stepTextScale(fontSize)`(顶层公开函数,便于单测):≤13px 不变;≥18px ×0.85 明显调小;13~18px 线性过渡(`1.0 - (fontSize-13)*0.03`)。**分段线性保证单调递增**,不会「大字比小字还小」。
- `_StepTextScaler`(私有 `TextScaler`)经 builder 里 `MediaQuery.copyWith(textScaler: ...)` 全局注入,所有页面生效。

## 三、约定与坑

- **`AppColors` 非 const**:所有字段是 getter,取值随「当前色板×亮度」运行时切换,引用处**不能放进 const 上下文**(const 里取不到运行时值,编译报错)。
- **`themeAnimationDuration` 为零**:不要改回默认 ~200ms 渐变——`AppColors` 取值是瞬时翻转的,渐变会让部分模块「慢半拍」;零渐变保证全模块同步瞬时切换。
- **页面跳转必须走 `AppRoutes`**:全 App 约定统一入口(便于将来切 go_router/深链);不要新增裸 `Navigator.push(MaterialPageRoute)`,除非是有意为之(如 `pushReplacement` 已封装)。
- **`AppTextField` 提交语义**:中文输入法下「完成」可能被当换行,组件用 `onChanged` 侦测结尾 `\n` 兜底转提交;重复提交靠 `submitLocked` 由上层配合「提交中」态去抖。
- **字号缩放档位与单调性**:`stepTextScale` 是分段线性函数,**改档位必须保持单调递增**(≤13 不动、≥18 ×0.85、中间线性),否则会「小字比大字大」;改完跑单测。
- **改共享组件的影响面**:
  - `frosted_snack.dart` 只是**转发层**,磨砂样式/动画的实现全在 `overlay_toast.dart`——改样式动后者,别在转发层里加逻辑。
  - `theme.dart` 的 `AppColors`/`AppTheme` 被全 App 引用,改取值规则会影响所有页面颜色。
  - 背景图透明判定在 `main.dart`(builder 画图)与 `theme.dart`(scaffold/AppBar 透明)两处重复,必须同步改。
- 侧边栏跳转前先 `Navigator.pop()` 关抽屉(系统设置与模块入口均如此)。
- 头像文件复制到应用文档目录 `avatar.jpg/png`(备份 zip 会带上,便于换机迁移);头像变更通过 `avatarVersion` ValueNotifier 通知首页等刷新。
- 抽屉头部图标连点 7 下 → 输入 6 位密码 → 隐藏的拓展服务页(`SecretUnlockTap`)。

## 四、常用改动点

- **加/改底部 Tab**:`bottom_nav.dart` 加 `_NavItem` + `main_shell.dart` 的 `_onTapTab` 与 `switch (_index)`(注意第 5 个闲话铺是特殊「启动器」Tab,不走 setState)。
- **加侧边栏模块入口**:`app_drawer.dart` 的 `_moduleTile(icon, label, page)` 加一行即可。
- **换/加主题色板**:`theme.dart` `kAppPalettes` 加 id(注意 `onPrimary` 对比度,黄色系需深色文字;`primarySoft`/`onPrimarySoft` 对 black/white 有特判)。
- **改背景图表现**:`main.dart` `_buildBackground`(透明度/模糊阈值/裁剪)+ `theme.dart` 的透明判定同步;范围参数在 `settings_service.dart` 的 clamp 里。
- **改页面切换动画**:`routes.dart` `_FadeSlideRoute`(时长/曲线/偏移)。
- **调全局字号缩放**:`main.dart` 顶层 `stepTextScale`(保持单调,可单测)。
- **新增全局提示**:直接 `OverlayToast.instance.show(...)` 或走 `frosted_snack.dart` 转发函数(带撤销用 `showUndoSnack`)。
- **新页面三态**:复用 `status_views.dart` 的 `LoadingView`/`ErrorView`/`EmptyView`,别各写一套。
- **新页面跳转/替换/清栈**:分别用 `AppRoutes.push` / `pushReplacement` / `pushAndRemoveUntil`。
