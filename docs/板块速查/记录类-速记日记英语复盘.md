# 记录类 板块速查(速记/日记/英语/复盘)

> 写给后续接手的 AI:先读 `交接文档.md` 与 `AI协作记忆.md`,本页是「记录类」局部速查。
> 覆盖模块:`lib/features/notes`(灵感速记)、`diary`(日记)、`english`(英文积累)、`review`(每日复盘)。
> 共性:四个模块都是**本地 SQLite + BaseDao 通用 CRUD**,页面结构都是「StatefulWidget 页面 + 各自 Service + 模型类」。

## 二、核心概念与数据流

### 灵感速记 notes —— 一句话:聊天式速记,收藏置顶,历史可检索
- **入口**:`main_shell.dart` 底部 Tab 2(`switch 2 => QuickNotePage`);`splash_page.dart` 启动页快捷入口(`AppRoutes.push(..., dialog: true)` 全屏对话框进入)。
- **DB 表 `notes`**:`id / content TEXT / created_at INTEGER / favorite INTEGER DEFAULT 0 / mood TEXT`(mood 可空)。
- **增**:`QuickNotePage._save()` → `NoteService.addNote(text)`(trim、空跳过)→ `insert`;`_saving` 去抖防「完成键+换行回调」重复保存;保存后清空、`_focusNode.requestFocus()` 保持聚焦连写。
- **删**:列表项 `Dismissible` 左滑 → `showConfirmDialog` 确认 → `deleteNote(id)` → `showUndoSnack('已删除', onUndo: restore)`;历史页可多选批量删(`deleteNotes` + 撤销);**详情页删除无撤销**,直接 pop 回列表(QuickNotePage 在 `_openDetail` await push 后 `_load()` 刷新)。
- **改**:收藏切换 `setFavorite(id, fav)`(`updateById`);`_display` 收藏置顶、其余按 `createdAt` 倒序;`_favOnly` 只看收藏。
- **查**:主页 `notes()` 全量加载内存排序;历史页 `_filtered` 纯内存过滤(关键字 contains + `dateKey` 比较 + 快捷区间/自定义起止),非 SQL 查询;`note_history_page` 时间轴色点按 `id % 8` 稳定取色。
- **共享组件**:`AppTextField`(autofocus: false、submitOnEnter: false、maxLength 200)、`showConfirmDialog`、`showFrostedSnack`、`showUndoSnack`、`MoodBadge`、`ErrorView`。

### 日记 diary —— 一句话:按天一篇的长文本写作,一天可多篇,历史只读回看
- **入口**:`quick_note_page` AppBar 右上角(menu_book 图标)、`home_page`(line 217)、`app_drawer`「写日记」。
- **DB 表 `diary_entries`**:`id / content TEXT / mood TEXT / entry_date TEXT(有索引,无唯一约束)/ created_at / updated_at`。v7 建表时 `entry_date` 有 UNIQUE,v10 重建表去掉唯一约束(一天可多篇),迁移见 `db_helper._migrateDiaryDropUnique`。
- **增**:`_save()` → `DiaryService.add(_date, content, mood)` **始终 insert 追加**(一天可多篇无上限);日期固定 `todayStr()`,不提供选日期(避免回填/篡改历史)。
- **删**:历史卡片/弹层删除 → 确认 → `deleteById` → `showUndoSnack` → `restore`(ignore 幂等)。「清空草稿」只清输入框,不动已存数据。
- **查**:`all()` 全量;历史 Tab 按 `entry_date` 分组、日期倒序、组内 `created_at` 倒序;点卡片弹 `showModalBottomSheet` + `DraggableScrollableSheet` 只读看全文(弹层内可删)。
- **共享组件**:`AppTextField`(minLines 10、maxLines null、maxLength 5000、submitOnEnter: false)、`MoodBadge`、`showConfirmDialog`、`showUndoSnack`、`ErrorView`、`SectionCard` 未用(日记自绘卡片)。

### 英文积累 english —— 一句话:离线每日内容 + 收藏 + TTS + 打卡金币
- **入口**:`app_drawer`「英文积累」。
- **内容来源**:每日一句 `DailyContent.englishFor(date)`(en+zh 池);单词/阅读/写作 `EnglishContent.wordsFor/readingFor/writingFor(date)`——均按 `Random(dateSeed(date))` **确定性选取**(同一天结果稳定),池可被 `ContentStore` 远程覆盖(热更不换包)。
- **DB 表 `english_favs`**:`id / fav_type TEXT / title TEXT DEFAULT '' / content TEXT NOT NULL / created_at / UNIQUE(fav_type, content)`。
- **收藏**:`EnglishService.toggle(type, title, content)` —— 在**同一事务**内「先查后删/插」,配合唯一约束 + `ConflictAlgorithm.ignore`,并发连点不重复收藏;UI 用 `_favKeys`(`'type:content'` 集合)O(1) 判断星标态。
- **打卡**:`CoinService.rewardEnglish(date)` → `rewardDaily(type: 'english', reason: '英文学习打卡', amount: 2)` 每日一次、受每日上限约束(返回 0 表示已达上限但已记打卡);`earnedOfType(date,'english') > 0` 判断今日已打卡(`_checkinDone`)。金币落 `coin_records` 表。
- **朗读**:`flutter_tts`,初始化 `setLanguage('en-US')`、`setSpeechRate(0.5)`;`dispose` 时 `_tts.stop()`。
- **共享组件**:`showFrostedSnack`、`ErrorView`;收藏/历史无删除撤销(取消收藏即删,无 confirm)。

### 每日复盘 review —— 一句话:每天一条的进度+完成/卡点/方案,upsert 保存
- **入口**:`app_drawer`「每日复盘」。
- **DB 表 `reviews`**:`id / review_date TEXT NOT NULL UNIQUE / progress INTEGER DEFAULT 0 / done TEXT DEFAULT '' / problem TEXT DEFAULT '' / plan TEXT DEFAULT '' / created_at`。
- **存**:`ReviewService.save(date, progress, done, problem, plan)` —— **事务内**查 `review_date` 后 insert 或 update(**upsert,每天一条**;UNIQUE 约束 + 事务串行化防并发重复);`_init` 同时 `Future.wait([all(), reviewFor(today)])` 回填今日输入框与进度。
- **查**:`all()` 按 `review_date DESC`;历史卡片:日期 + 完成度% + `LinearProgressIndicator` + `ExpansionTile` 展开「完成/卡点/明日方案」。
- **删**:页面代码**无删除功能**(未确认是否有意为之)。
- **共享组件**:`SectionCard`(三个输入区块)、`showFrostedSnack`、`ErrorView`;输入用**原生 `TextField`**(非 AppTextField),maxLength 200 且 `counterText: ''` 隐藏计数。

## 三、约定与坑

- **速记不选心情,老数据 mood 显示保留**:`QuickNotePage._save()` 调 `addNote(text)` **不带 mood**(交接文档:已删除心情选择);但列表/历史/详情仍按 `note.mood != null` 渲染 `MoodBadge`——老记录的心情徽章不能丢。
- **输入框 autofocus 约定**:速记输入框 `autofocus: false`——底部导航切过来是浏览场景,避免「一看功能就被键盘打断」;想写时点输入框再弹键盘。
- **AppTextField 提交语义**:默认 `submitOnEnter: true`(回车/完成=提交,内部用 onChanged 侦测结尾换行兜底);**长文本(日记、速记)必须 `submitOnEnter: false`**,回车正常换行;提交去抖靠上层 `_saving` 标志(速记 `_saving`、日记 `_saving`)。
- **删除一律可撤销(详情页除外)**:速记单条/批量、日记删除均走 `showUndoSnack` + `restore()`(`insert(..., conflictAlgorithm: ConflictAlgorithm.ignore)` 幂等,记录实际未被删时跳过不抛主键冲突);**`note_detail_page` 的删除直接 pop,无撤销**。批量删除前有「不可恢复」措辞确认,但实际仍可撤销(文案与现实略不符,改动时留意)。
- **BaseDao 只覆盖通用 CRUD**:事务性/复杂逻辑留在各 Service 自实现——`EnglishService.toggle`(收藏事务)、`ReviewService.save`(upsert 事务)都直接用 `dbHelper.database` 起 `db.transaction`;`DbHelper` 是单例,`dbHelper` getter 在 BaseDao 里。
- **唯一约束兜底并发**:`reviews.review_date`、`english_favs(fav_type, content)` 有 UNIQUE;并发连点靠「事务 + ignore/查重」兜底,不要裸 insert 依赖异常。
- **notes 表历史坑(v11)**:早期 `_onCreate` 漏建 `favorite/mood` 列,导致全新安装用户保存失败;现在迁移用 `_ensureNotesColumns` 按列存在性补齐,`_onCreate` 已含两列——**改表结构时迁移要按列存在性判断,避免「重复列」报错**。
- **日记日期固定今天**:不提供日期选择(注释明说避免回填/篡改历史);`entry_date` 从 v10 起**无 UNIQUE**(一天多篇),历史分组按该字段。
- **加载失败统一 ErrorView + 重试**:各页 `_loadError` + `ErrorView(onRetry: ...)`;日志统一 `AppLog.instance.e('...')`,失败操作显式落日志 + `showFrostedSnack` 反馈(不再静默)。
- **英文内容确定性选取**:`dateSeed(date)` 作随机种子,同一天结果稳定;远程覆盖走 `ContentStore`(quotes/english/words/readings/writings 等字段),本地池在 `daily_content.dart` / `english_content.dart`。
- **打卡判定**:`earnedOfType(date, 'english') > 0` 视为已打卡(金币表中 type='english');`rewardEnglish` 返回 0 表示已达上限但打卡已记录——UI 两种返回都置 `_checkinDone = true`。
- **跳转统一 `AppRoutes.push`**(淡入+上滑);启动页速记入口用 `dialog: true` 全屏对话框。
- **`MoodDot` 不存在**:全库 grep 无此组件(交接文档记载:曾短暂改为纯彩点,用户要求回退,已恢复文字标签 `MoodBadge`)。

## 四、常用改动点

- **速记加字段/改保存**:`note.dart`(模型+fromMap/toMap)→ `db_helper.dart` 迁移(按列存在性)+ 新装 `_onCreate` → `note_service.dart`(如加参数);`quick_note_page._save` 决定是否带新字段。
- **速记排序/置顶规则**:`quick_note_page._display`(收藏置顶+时间倒序)或 `note_service.defaultOrderBy`。
- **速记历史筛选**:`note_history_page._filtered`(纯内存过滤)+ `_Range` 枚举 + `_chip` 快捷项;时间轴色点池 `_dotColors`。
- **日记写作区/历史**:`diary_page._buildEditor`(输入区/心情 chips/按钮)、`_buildHistory`(日期分组)、`_openHistory`(只读弹层);改「一天多篇」行为别动 `_migrateDiaryDropUnique` 之外的 schema。
- **英文内容池**:改每日单词/阅读/写作 → `core/data/english_content.dart`(或远程 `ContentStore`);改打卡奖励 → `coin_service.rewardEnglish`(金额/每日次数)。
- **英文收藏逻辑**:`english_service.toggle`(事务、唯一键);UI 星标态 `english_page._favKeys`(改键格式要同步 `_toggle` 里的 `'$type:$content'`)。
- **复盘字段/文案**:`review_page` 三输入区(原生 TextField)+ `_progressValues` 档位;保存逻辑 `review_service.save`(upsert);历史卡片 `_historyCard`。
- **共享组件调整**(影响本板块):`app_text_field.dart`(提交语义)、`frosted_snack.dart`(showUndoSnack 时长 4s)、`mood_badge.dart`(moodDefs 颜色/文案)。
