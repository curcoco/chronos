## 二、核心概念与数据流

### 健康模块

- **定位**:纯本地健康管理,无云同步。「智能食谱」已舍弃(`health_page.dart` 注释:原 5 Tab 减为 4)。
- **主链路**:`HealthPage.initState → _load()` 用 `Future.wait` 并行查 `kitchen_items` / `workouts` / `user_videos`(均 `orderBy: created_at DESC`)→ 数据下发给各 Tab → 任一 Tab 增删后回调 `onChanged(_reload)` 全量重查。热力图 Tab 是 Stateless,靠父级 reload 传入新 workouts 刷新。
- **打卡链路(联动金币)**:运动打卡 `HealthWorkoutTab._checkin → CoinService.rewardWorkout(todayStr())`;视频打卡 `HealthVideoTab._checkin`(要求已计时 `_sec > 0`)→ `CoinService.rewardVideo(todayStr())`。均「每天每类一次」,由 `coin_records` 查重,受每日金币上限约束(见 `lib/features/coins/services/coin_service.dart` 的 `rewardDaily`)。
- **DB 表**(建表在 `lib/core/services/db_helper.dart`):
  - `kitchen_items`:`id / cat TEXT / name TEXT / cal INTEGER DEFAULT 0 / price REAL DEFAULT 0 / link TEXT DEFAULT '' / created_at INTEGER`
  - `workouts`:`id / type TEXT / minutes INTEGER / work_date TEXT / created_at INTEGER`
  - `user_videos`:`id / title TEXT / path TEXT / note TEXT DEFAULT '' / created_at INTEGER`(v13 起新增,path 是应用文档目录内文件的绝对路径)
  - `health_settings`(key/value):建表 SQL 存在,但全库代码无任何引用(死表,疑似历史遗留)。

### 屏幕时间(防沉迷,v18 起)

- **定位**:读系统记好的账,不自己监控——「使用情况访问」是特殊权限(AppOps),app 不能代点,只能引导用户去系统设置开;授予后 `UsageStatsManager.queryEvents` 查各 app 前台时长。**无常驻后台**:打开页面时同步最近 8 天(每天一次通道查询,当天截至当前时刻)。
- **数据流**:进 Tab → `hasPermission`(无 → 权限门卡片;从系统设置返回时 `didChangeAppLifecycleState.resumed` 自动重检)→ `syncRecent(8)`:逐天 `queryUsage` → 按分类聚合写 `screen_usage`(当天整体重写;查询为空的旧日子跳过不动)→ 并行查 今日娱乐/今日总屏幕/昨日/热力图/排行 → 昨日达标则 `maybeRewardYesterday` 发金币。
- **分类三级**:用户覆盖(`screen_app_categories`)> 内置预设(`builtinEntertainment` 约 28 个常见娱乐包名:抖音/B站/王者/网易云…)> 默认工具(不进娱乐统计)。分类页可改可「恢复默认」;`screen_usage.category` 是写入时的分类快照(便于历史统计,改分类不改历史)。
- **金币联动**:昨日有数据 且 娱乐 ≤ 预算 → `CoinService.rewardScreen(今天)` 发 2 枚(type `screen`,每天一次+每日上限;UI 同时查 `earnedOfType` 区分「已奖/已达上限」)。娱乐预算(分钟)存 `SettingsService.screenBudgetMinutes`(默认 120,30~300)。
- **热力图**:GitHub 式 53 周(列=周、行=周日~周六),色阶与运动日历同语言(0xFFE9F0F7→0xFF0288D1 五档,阈值 0/30/60/120 分钟);月份标注行 + 左侧一/三/五;横向滚动、`postFrameCallback` 跳最右(最近一周)。
- **DB 表**(v18):
  - `screen_app_categories`:`package TEXT PRIMARY KEY / category TEXT / updated_at INTEGER`
  - `screen_usage`:`day TEXT / package TEXT / category TEXT / seconds INTEGER, PRIMARY KEY(day, package)`
- **测试**:`test/screen_time_service_test.dart`(分类优先级/统计/金币去重/无通道降级,7 项)。注意它把 ffi 库目录指到独立临时目录(`setDatabasesPath`)——`flutter test` 并发跑套件,多个套件共用默认目录的 `student_workbench.db` 会互相删库。

### 记账模块

- **定位**:纯本地生活记账。入口:`lib/features/shell/pages/main_shell.dart` 底部导航 index 3,`splash_page.dart` 可直达;另被闲话铺工具 `get_balance` 读取(`lib/features/chat/tools/tool_registry.dart`,查余额/预算/今日收支/金币)。
- **主链路**:`LedgerPage._load` 并行查 `txns / startBalance / budget / customCats` → 余额 = `startBalance + Σincome − Σexpense`;本月收支按 `date.startsWith(monthKey(now))` 过滤。记一笔/编辑/删除/改设置后 `onChanged=_load` 全量刷新;明细删除时先用 `onRemove` 同步移除该行(见下)。
- **打卡链路**:记一笔且日期为今天 → `addTxn` 成功后 `CoinService.rewardLedgerCheckin(todayStr())`;提示文案按实际发币数区分「记账打卡成功,金币 +n」/「已记一笔」。
- **DB 表**:
  - `ledger_txns`:`id / type TEXT / amount REAL / category TEXT / note TEXT DEFAULT '' / txn_date TEXT / created_at INTEGER`,且有索引 `idx_ledger_date ON ledger_txns(txn_date)`
  - `ledger_settings`:`key TEXT PRIMARY KEY / value TEXT`,实际键:`start_balance`、`budget`、`custom_cats`(JSON 字符串数组)

## 三、约定与坑

### 金额校验 / 事务

- **服务层校验** `LedgerService._validate`(addTxn/updateTxn 都先过):金额必须 `isFinite` 且 `0 < amount ≤ 99999999`,否则抛 `ArgumentError`;`type` 必须在白名单 `expense/income`;`category` 非空。
- **UI 层校验** `LedgerEntrySheet._submit`:解析失败或 ≤0 →「请输入有效金额」;>99999999 →「金额过大」;提交前 `amount = double.parse(amount.toStringAsFixed(2))` 去浮点尾差。
- **厨房条目校验在 UI 层**(`health_kitchen_tab._save`):卡路里必须整数、价格必须数字,「填了但非法要明确提示,不再静默存 0」;负数拒绝。
- **事务**:记账单条增删改无显式事务;金币每日打卡的「查重 + 发放」在 `CoinService.rewardDaily` 内 `db.transaction` 完成,防连点重复发放。
- **幂等撤销**:`restoreTxn` 用 `ConflictAlgorithm.ignore` 插回——撤销时若原行其实没删成功,不会抛主键冲突。

### 视频上传 / 删除清理

- 上传链路(`health_video_tab._upload`):`FilePicker` 选视频 → 复制到 `getApplicationDocumentsDirectory()/video_<时间戳>.<原扩展名>` → 弹「标题/备注」对话框 → `addUserVideo` 入库。
- **取消对话框时删除已复制文件**(不留孤儿文件);但**入库失败走 catch 分支时未删 dest,可能留孤儿文件**(未确认)。
- 删除视频:先删 DB 行,再尽力删本地文件(失败仅记日志,不影响删除);播放前检查 `File(v.path).existsSync()`,文件被移动则提示。

### 撤销删除(showUndoSnack)

- **仅记账明细有撤销**:左滑(`Dismissible`,`endToStart`)→ `confirmDismiss` 确认弹窗 → `onDismissed → _deleteAndUndo`:①先 `widget.onRemove(t)`(父页 setState 移除行,满足 Dismissible「被删行必须立刻离开树」约束)→ ②`deleteTxn` → ③`showUndoSnack`(4 秒,`onUndo = restoreTxn + onChanged`)。若 DB 删除失败 → `onChanged` 整页重载恢复 + 提示。
- 健康各 Tab 删除只有确认弹窗,**无撤销**(厨房条目、自传视频);视频删除确认文案会说明本地文件一并删除。
- `showUndoSnack` 定义在 `lib/core/widgets/frosted_snack.dart`(基于 `OverlayToast`,不排队、只显示最新一条)。

### 图表 / 联动刷新

- 明细、日历、图表、余额卡全部**共享父级 `_txns`**,热力图共享父级 `_workouts`;任何增删改走 `onChanged=_load` 全量重查,统计自然联动。唯一局部操作是明细删除行的 `onRemove` 同步移除。
- 明细 Tab 内部 `_offset`(月份翻页)与 `_limit`(分批渲染,默认 50,「加载更多」+50)是组件内 state,reload 不重置翻页位置;日历 Tab 的 `_offset/_dayKey` 同理。
- 日历热力只统计支出(`expenseByDay` 过滤 `type=='expense'`),但点选某天后展示的**当天全部流水**(含收入)。

### 其他坑

- 金额一律 double 存储、`money()`(`toStringAsFixed(2)`)展示;收支颜色/符号:收入绿 `+`、支出红 `−`(明细/日历共用)。
- 分类规则:支出 = `presetExpense`(餐饮/交通/购物/学习/娱乐/医疗/其他)+ 自定义;收入 = `presetIncome`(零花钱/兼职/红包/其他)+ 自定义(自定义两类共享);切换收支类型时 `_category` 重置为对应列表第一项;预设分类不可删,只能删自定义。
- 预算预警画在记账页 hero 余额卡(「已用 n% / 已超支!」);`ledger_cats_tab` 提示文案写「超支会在首页余额卡上预警」,但全库未发现 home 页面引用 budget(疑似文案过时,未确认)。
- 打卡返回 `coin > 0` 表示本次实际发币,否则提示「今日已打过卡」。
- 视频计时器状态自持于 `HealthVideoTab` state,靠父级 `TabBarView` 缓存保证切 Tab 不重置;`dispose` 时 cancel Timer。
- 厨房/运动/视频列表均按 `created_at DESC` 查询;运动记录再按 `date` 降序分组展示(同一天内顺序未再排序,未确认)。
- 无 health/ledger 专属测试文件(`test/` 下无对应用例)。

## 四、常用改动点

- **改健康内容池**(分类/运动类型/内置跟练):`lib/core/data/health_content.dart` 的 `kitchenCats` / `workoutTypes` / `videoPool`(视频池可被 `ContentStore` 远程覆盖)。
- **改健康/记账表结构**:`lib/core/services/db_helper.dart` 建表 SQL + 版本迁移,再同步 `models/` 与对应 `Service`。
- **改记账金额上限或规则**:双处——`LedgerService._validate`(服务层)与 `LedgerEntrySheet._submit`(UI 层)。
- **改明细行交互**(编辑/删除/撤销):`ledger_detail_tab.dart` 的 `_txnRow` / `_editTxn` / `_deleteAndUndo`。
- **改余额卡 / 预算预警**:`ledger_page.dart` 的 `_buildHero`。
- **改打卡奖励**:`health_workout_tab.dart`、`health_video_tab.dart`、`ledger_page.dart` 的调用点;奖励数值在 `coin_service.dart` 的 `rewardWorkout` / `rewardVideo` / `rewardLedgerCheckin`(屏幕时间达标是 `rewardScreen`,由 `screen_time_service.maybeRewardYesterday` 内部调)。
- **改屏幕时间**(预设清单/同步天数/热力图阈值/预算范围):`screen_time_service.dart`(`builtinEntertainment`/`syncRecent`)+ `health_screen_time_tab.dart`(`_heatColor`/预算滑杆)+ `settings_service.dart`(`screenBudgetMinutes`);原生侧 `ScreenTimePlugin.kt`。
- **改明细分批渲染**:`ledger_detail_tab.dart` 顶部 `_limit = 50`。
- **新增跨模块联动**(如给聊天工具提供数据):参考 `lib/features/chat/tools/tool_registry.dart` 的 `get_balance`。
- **页面入口**:健康 = 抽屉(`lib/features/shell/widgets/app_drawer.dart`);记账 = 底部导航(`lib/features/shell/pages/main_shell.dart` index 3)与 `splash_page.dart` 直达。
