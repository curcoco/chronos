## 二、核心概念与数据流

### 首页卡片组成(自上而下)

1. `HomeHeader`(日期+星期+金句+头像)
2. `HomeOnboardingCard` —— 仅首次(`isOnboardingDone()==false` 时显示)
3. `HomeWeatherStrip` —— 仅配置天气 key 后显示,失败静默隐藏
4. `HomeCoinCard`(余额 + 今日已赚 `/10`,点击进金币中心)
5. 「记一笔」快捷按钮 —— 弹 `LedgerEntrySheet`;当天记账触发 `rewardLedgerCheckin`(+1,每日一次)
6. `HomeTodayCard`(今日任务,最多展示 3 条)
7. `HomeNoteCard`(灵感速记 → `NoteService.addNote`,同步到灵感专区)
8. `HomeEnglishCard`(每日英语一句)

数据加载:`_init()` 用 `Future.wait` 并行取 6 项(`todayTasks` / `balance` / `earnedToday` / `nickname` / `isOnboardingDone` / `avatarPath`),随后 `_loadWeather()`;任一失败 → `ErrorView` + 重试(不永久转圈)。下拉刷新走 `_reload()`。头像变化经 `SettingsService.avatarVersion` 监听刷新。

### 任务:排序 / 自动生成 / 完成链路

- **排序**:`TaskService.sortTasks`(静态):未完成在前 → 优先级(0高→2低)→ `createdAt`;查库后在内存排序。
- **自动生成**:`todayTasks(date)` 先 `ensureDailyTasks(date)` —— 单事务内 `COUNT` 判断当日是否已有任务,没有则按 `DailyContent.autoTasksFor(date)` 插 3 条(`auto=true, priority=1` 中)。并发进入不会重复生成,失败整体回滚。
- **完成链路**:UI(首页/计划中心)→ `confirmTaskToggle` 确认弹窗 → `TaskService.toggleTask`(单事务)→ 更新 `done=1` → `rewardTask`(+1,受上限)→ 若 `isAllDone` 再 `rewardAllDone`(+3,每天仅一次)。
- **取消完成**:`toggleTask` 另一分支:更新 `done=0` → `revokeTask`(删该任务当日 `type='task'` 记录,优先按 `task_id`,旧数据按 `reason` 兜底)→ `revokeAllDone`(删当日全部 `type='bonus'` 记录)。返回值正=获得、负=收回。
- **已完成任务不支持任何操作**(首页 `onTap=null`、计划中心 Checkbox 禁用、无取消按钮),从源头杜绝重复发币。
- **随机任务**:`RandomTaskSheet` → `DailyContent.randomAutoTask(exclude 今日已有标题)` → `addTask(auto:true)`,不影响每日自动生成的 3 条。
- **本周计划/长期目标**:`PlanPage` 三 Tab;两个 `PlanListView` 共用(scope 区分);`PlanService.list` 排序 `done ASC, sort_order ASC, created_at ASC`;「随机生成」用 `randomWeekPlan` / `randomLongTermGoal`(排除已有标题)。

### 金币发放规则与事务化

- **常量**(`coin_service.dart`):`dailyCap=10`、`taskReward=1`、`bonusReward=3`。
- **`grantable(earned, amount)` 纯函数**:`min(amount, cap-earned)` 且不为负;所有发放先经它,杜绝超发(剩 0/1 额度时只发 0/1)。
- **发币**:`rewardTask`(查额度+写记录同事务);`rewardAllDone` 先查当日 `type='bonus'` 是否已存在(每天一次),查重+发放同事务防并发重复发。
- **打卡奖励**:`rewardDaily(type, reason, amount)` 每天每类一次、受上限;便捷方法 `rewardEnglish`(+2)/ `rewardLedgerCheckin`(+1)/ `rewardWorkout`(+1)/ `rewardVideo`(+1)。
- **余额/统计**:余额 = `SUM(amount)` 全表;`earnedToday` 只统计当日 `amount > 0`。
- **记录类型**:`task` / `bonus` / `redeem`,以及 english / ledger / workout / video 等打卡类。

### 心愿兑换(金币中心)

- 列表:未兑换在前、新建在前(`WishService` 默认排序)。
- 兑换:`CoinService.redeemWish(wish, date)` —— 单事务:余额 `< cost` → false;插入 `-cost` 的 `redeem` 记录;`UPDATE wishes SET redeemed=1 WHERE id=? AND redeemed=0`,影响 0 行说明已被并发兑换 → 抛 `_RedeemConflict` 回滚扣款 → 外层转 false。防并发/重复兑换超扣。
- UI:余额不足时兑换按钮禁用;兑换前二次确认。
- 随机心愿:`WishContent.randomWish(exclude 已许过的)`;池子用尽提示自定义添加。
- 删除心愿:先删再弹 `showUndoSnack`,撤销走 `WishService.restore`(按原 id 插回,`ConflictAlgorithm.ignore` 幂等);删除不影响已产生的金币收支记录。

## 三、约定与坑

- **金币事务原子性**:任务 `done` 状态变更与金币发放/收回必须同一事务(`toggleTask` 把 `txn` 作为 `executor` 传入 `CoinService`,`CoinService` 内部方法也各自开事务);任一步失败整体回滚,不会出现「勾选成功但没发币 / 取消成功但币没收回」的分叉。
- **每日上限 10 是硬约束**:`grantable` 兜底;已达上限时完成不再得币,确认弹窗会提示「今日已达每日上限,完成不再获得金币」。
- **撤销/收回靠删记录**:`revokeTask` 优先按 `task_id` 精确删,旧版本记录无 `task_id` 时按 `reason = '完成今日任务:{title}'` 兜底匹配——**reason 字符串不能改**,否则旧记录收不回。
- **兑换防并发**:`UPDATE ... WHERE redeemed=0` 影响行数判断竞态 + 异常回滚,`_RedeemConflict` 是内部信号类,勿在外部捕获处理。
- **已完成任务不可逆操作**:首页与计划中心对已完成任务均禁用点击/勾选;删除任务只对未完成任务开放。
- **AppColors 是 getter 非 const**(取值随「色板 × 明暗」运行时切换,不能放进 const 上下文)。
- **渐变卡配色约定**:`LinearGradient(begin: topLeft, end: bottomRight, colors: [AppColors.primaryLight, AppColors.primarySoft])`,前景用 `AppColors.onPrimarySoft`(金币卡另带 `primary` 0.3 透明阴影)。注意黑/白「经典」色板下 `primarySoft = primary`、`onPrimarySoft = onPrimary`(深色文字变白字)。
- **分类/优先级标签**:`categoryColor(category)` 按 `hashCode` 取 8 色之一(同分类颜色稳定);`PriorityTag` 0高红 / 1中橙 / 2低绿。
- **日期统一 `yyyy-MM-dd`**(`todayStr()` 生成,代码里不要手拼);确定性随机用 `dateSeed(date)`(去掉横杠的整数作种子),同一天结果稳定。
- **`ensureDailyTasks` 事务防并发重复生成**:首页刷新/多入口同时进不会生成两批 3 条。
- **首页加载失败渲染 ErrorView(可重试)而非永久转圈**;天气失败静默隐藏,不打扰用户。
- **首页任务卡 >3 条**时卡片内部 120 高 `ListView` 上滑查看全部。
- **「记一笔」当天记账会打卡发币**(`rewardLedgerCheckin` +1 每日一次,受上限)。
- **收支记录样式**:`coin_center_page._RecordTab` 里按 `type` 的 switch 决定图标与颜色,新增类型要同步这里。
- **表结构**(`db_helper.dart`):`tasks`(task_date 索引)、`coin_records`(rec_date 索引;v2 迁移加 `task_id`)、`wishes`、`plan_items`(scope 索引);改结构要递增 `dbVersion` 并在 `runMigrations` 加迁移。

## 四、常用改动点

- **改首页卡片顺序/增删**:`home_page.dart` 的 `build` 组装处(改完记得同步各卡片 widget)。
- **改金币数值/每日上限**:`coin_service.dart` 顶部常量(`dailyCap` / `taskReward` / `bonusReward`)+ `plan_page.dart` 的规则提示文案(「+1 / +3 / 最多 10 枚」)。
- **改每日自动任务 / 随机任务池 / 金句 / 英语**:`lib/core/data/daily_content.dart`(或远程 `ContentStore` 覆盖,不换包热更)。
- **新增打卡奖励类型**:`CoinService.rewardDaily` + 便捷方法 + 对应业务调用点 + 收支记录 switch 分支。
- **改任务完成交互/文案**:`task_confirm_dialog.dart`(确认弹窗)+ `task_service.toggleTask`。
- **改计划中心结构**:`plan_page.dart`(Tab 结构);计划列表交互在 `plan_list_view.dart`(左滑编辑/删除、随机生成)。
- **心愿相关**:池子在 `wish_content.dart`;CRUD 在 `wish_service.dart`;页面在 `coin_center_page.dart` 的 `_WishTab`。
- **配色/主题调整**:`lib/core/theme.dart`(`AppPalette` 色板、`AppColors` 语义色)。
